1. Read [docs/CONTEXT.md](docs/CONTEXT.md) for the repository map, and [docs/GUARDRAILS.md](docs/GUARDRAILS.md) for the rules.

5. Run the quality gates in `.github/copilot-instructions.md` before finishing.
